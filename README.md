# Laura Berezin Jadzinsky | Portfolio

My personal portfolio, built with HTML, CSS, and JavaScript.

## Files

- `index.html`: page content, project summaries, and links.
- `styles.css`: colors, typography, layout, and responsive styles.
- `script.js`: project details, filters, and interactive behavior.

## Preview locally

Keep the three files in the same folder and open `index.html` in a browser. Alternatively, run `python3 -m http.server 8000` from that folder and open http://localhost:8000.

## Make changes

Edit visible page text in `index.html`. Edit the `projects` object in `script.js` to change text shown in project detail windows. Edit `styles.css` to customize the design.

## Hosting

These files are a standalone copy of the portfolio. Changes to this GitHub repository do not automatically update the version hosted with ChatGPT Sites. GitHub Pages can publish this repository separately when configured to serve the root directory of the main branch.
